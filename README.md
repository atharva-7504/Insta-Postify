# Insta-Postify

Created simple Projects to understand and practice the CRUD implementations using HTTP methods

🔁 REST APIs use simple HTTP methods we interact with daily:

* GET → Fetch data

* POST → Create data

* PUT → Update entire data

* PATCH → Update specific fields

* DELETE → Remove data
